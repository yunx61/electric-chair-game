# ELECTRIC CHAIR DUEL v3.0

スマホのブラウザで遊べる、非公式ファンメイドの電撃心理戦ゲームです。
番組ロゴ・映像・実際の効果音などの固有素材は使用せず、雷・煙・メタリック文字・円形の12脚という要素でオマージュしたオリジナルUIにしています。

## v3.0の主な機能

- 1〜12番の12脚を円形に配置
- 2人のリアルタイム通信対戦
- 招待リンク（Web Share / LINE / X / メール / コピー）
- HOMEタブから開けるルール説明
- AIとの1人対戦
- AI難易度：EASY / NORMAL / HARD
- AIキャラクター4種類
  - レイ：冷徹分析型
  - ゴウ：強気ギャンブラー
  - ミカ：読心トリックスター
  - ナギ：慎重な守備型
- 難易度と性格が、仕掛け位置・着席位置の選択ロジックに反映
- HARDは過去のプレイヤー選択傾向を強く参照（現在の電気イス位置は参照しない）
- SAFE後に、そのターンで仕掛けられていた電気イスを円形表示で公開
- Web Audio APIによるオリジナル効果音
- 対応ブラウザで振動演出
- 再接続・再戦・シリーズ勝数

## ルール

1. 毎ターン、仕掛け側が残っているイス1脚に電気を設定します。
2. 座る側がイスを1脚選びます。
3. SAFEならイス番号と同じポイントを獲得し、そのイスは取り除かれます。
4. 電気イスなら現在のポイントが0になり、感電回数が1増えます。感電したイスは残ります。
5. 40ポイント到達で勝利、3回感電で敗北、残り1脚では高得点側が勝利です。

## 起動

Node.js 18以上。

```bash
npm start
```

デフォルトでは `http://localhost:3000` で起動します。
Renderでは `render.yaml` を利用できます。
