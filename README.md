# ELECTRIC CHAIR DUEL

スマホのブラウザ2台で通信対戦できる、2人用リアルタイム心理ゲームです。

## 起動

依存パッケージはありません。Node.js 18以上で:

```bash
npm start
```

その後 `http://localhost:3000` を開きます。

同じLAN内のスマホから試す場合は、PCのLAN内IPを使って `http://<PCのIP>:3000` を2台の端末で開いてください。

インターネット越しに遊ぶ場合は、Node.jsの常駐プロセスとWebSocketを扱えるホスティングへこのフォルダをそのまま配置してください。HTTPS環境では自動的に `wss://` を使用します。

## 実装済み

- 6桁ルームIDで2人対戦
- サーバー権威型の得点・勝敗判定
- 電気イス番号を相手クライアントへ送らない秘密情報設計
- セーフならイス番号を加点し、そのイスを除外
- 感電なら現在得点を0へ、感電イスは場に残る
- 40点到達で勝利
- 3回感電で敗北
- 残り1脚でゲーム終了し、得点が多い側が勝利
- 再読み込み・一時切断からの再接続
- 90秒再接続されない場合の不戦敗
- スマホ縦画面UI
- 電撃・警告灯をイメージしたオリジナル演出
- 対応端末ではバイブレーション

## ルール上の補足

番組ルールの整理として、セーフ時のみ座ったイスを取り除き、感電したイスは残る方式です。残り1脚になった時点で終了します。

残り1脚時に同点だった場合について、参照した公開情報で明示を確認できなかったため、このアプリでは **DRAW** としています。

## 権利表記について

これは非公式のファンメイド実装です。TBSの番組ロゴ、番組映像、写真、公式音源、公式UI素材は使用していません。番組の緊張感を連想させる「黒・黄・赤、金属、警告表示、電撃」という一般的なモチーフで独自デザインしています。

## Renderへ無料デプロイ

このリポジトリには `render.yaml` を同梱しています。Render Blueprintとして読み込むと、Node.jsの無料Web Serviceとして作成できます。

設定内容:

- type: web
- runtime: node
- plan: free
- buildCommand: npm install
- startCommand: npm start
- GitHubへのコミットで自動デプロイ

サーバーは `process.env.PORT` を使用し `0.0.0.0` にbindするため、RenderのWeb Service要件に対応しています。

注意: Render無料Web Serviceは一定時間アクセスがないとスリープします。再アクセス時は起動待ちが発生することがあります。
