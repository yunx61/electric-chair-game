# Electric Chair Duel

2人用のリアルタイム通信対戦Webゲームです。Node.js標準機能 + 同梱WebSocket実装のみで動作します。

## 主な機能

- 1〜12番のイスを円形に配置
- 6桁ルームID / 招待URL
- WebSocketリアルタイム対戦
- サーバー権威型判定（仕掛けた番号は相手へ送信しない）
- 40PT到達 / 3回感電 / 残り1脚で終了
- 感電時は得点を0へ、セーフ時のみイス除外
- 接続状態・相手待機表示
- 切断後90秒の再接続猶予
- 選択確認ダイアログ
- 段階式の判定・電撃演出
- Web Audio APIによるオリジナル効果音
- 両者同意式の再戦
- ルーム内の連戦勝数表示
- iPhone / Androidの縦画面対応

## 起動

Node.js 18以上。

```bash
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## Render

`render.yaml` 同梱。GitHubへ配置後、RenderのBlueprintからデプロイできます。

ヘルスチェック: `/health`

## 注意

非公式ファンメイドです。番組ロゴ・映像・音源などの固有素材は使用していません。
