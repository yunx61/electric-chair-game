# ELECTRIC CHAIR DUEL v3.1

スマホのブラウザで遊べる、非公式ファンメイドの電撃心理戦ゲームです。
番組ロゴ・映像・実際の効果音などの固有素材は使用せず、雷・煙・メタリック文字・円形の12脚という要素でオマージュしたオリジナルUIにしています。

## v3.1 改善点

- スマホ縦画面のゲームUIを1画面に再設計（ページ縦スクロール不要）
- 勝敗条件を満たしたターンでも、SAFE / 感電 / 罠公開の結果演出が完了してからGAME OVERへ移行
- SAFE後、ミニ表示だけでなく本体の円形12脚でも「仕掛けられていた椅子」を赤く発光表示
- 安全に座った椅子を本体円形盤で緑表示
- GAME START / VS の開始演出追加
- BGM / SE のON・OFF設定追加（端末に保存）
- AIキャラクターを人物風のオリジナルアバター表示へ変更
- HARD AIの行動モデルを強化。得点、感電回数、過去の着席・仕掛け傾向を加味
- AIは現在の正解の電気イス番号を参照せず、履歴だけで判断
- 通信切断時の再接続猶予を90秒から180秒へ延長
- 進行中ルームをサーバー内スナップショットへ保存し、同一ファイルシステム上のプロセス再起動時に復元を試行
- 静的ファイル配信のパス検証を強化

## 主な機能

- 1〜12番の12脚を円形に配置
- 2人のリアルタイム通信対戦
- 招待リンク（Web Share / LINE / X / メール / コピー）
- HOMEタブから開けるルール説明
- AIとの1人対戦
- AI難易度：EASY / NORMAL / HARD
- AIキャラクター4種類
  - レイ：冷徹分析型
  - ゴウ：強気ギャンブラー
  - ミカ：読心トリックスター
  - ナギ：慎重な守備型
- SAFE後に、そのターンで仕掛けられていた電気イスを公開
- Web Audio APIによるオリジナル効果音・低音アンビエンス
- 対応ブラウザで振動演出
- 再接続・再戦・シリーズ勝数

## ルール

1. 毎ターン、仕掛け側が残っているイス1脚に電気を設定します。
2. 座る側がイスを1脚選びます。
3. SAFEならイス番号と同じポイントを獲得し、そのイスは取り除かれます。
4. 電気イスなら現在のポイントが0になり、感電回数が1増えます。感電したイスは残ります。
5. 40ポイント到達で勝利、3回感電で敗北、残り1脚では高得点側が勝利です。

## 起動

Node.js 18以上。

```bash
npm start
```

デフォルトでは `http://localhost:3000` で起動します。
Renderでは `render.yaml` を利用できます。

### Render無料枠について

ルーム状態のスナップショットは同一ファイルシステム上でのプロセス再起動に備えるためのベストエフォートです。Render無料Web Serviceのファイルシステム自体が破棄される再配置・インスタンス交換では保持されない場合があります。
